# Leone Rock Premier League logos

Upload verified logo image files for the Leone Rock Premier League here.

Recommended structure:
- `league/` — official Leone Rock Premier League competition logo.
- `clubs/` — club crests, one image per club.

Use clear filenames, for example:
- `league/leone-rock-premier-league.png`
- `clubs/club-name.png`

Preferred formats: PNG (transparent background where possible), WebP, or JPG.
Keep original image proportions and use high-resolution files. Do not upload the SLFA crest as a substitute for a competition or club logo.

Adding files to this folder does not automatically change the logos displayed in the app; the app's logo references must also be updated to point to the uploaded files.
